# Logistic Regression — Spam Email Classification

A simple **Logistic Regression** model built from scratch for binary classification of emails as **Spam** or **Ham**.

## Results

* **Accuracy:** 98%
* **Test samples:** 48,463
* **Precision:** 0.98
* **Recall:** 0.98
* **F1-score:** 0.98

## Dataset

The model uses the **190K Spam/Ham Email Dataset** from Kaggle:

[Kaggle Dataset — 190K Spam/Ham Email Dataset](https://www.kaggle.com/datasets/meruvulikith/190k-spam-ham-email-dataset-for-classification?utm_source=chatgpt.com)

The dataset is not included in this repository due to its size.

## Tech Stack

* Python
* NumPy
* Pandas
* Logistic Regression
* Scikit-learn (for evaluation)

## Project

This project was built as a practical implementation of Logistic Regression for text classification and to understand the underlying machine-learning workflow.
